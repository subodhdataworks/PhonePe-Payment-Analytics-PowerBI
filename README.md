# 📊 PhonePe Payment Analytics Dashboard | Power BI

An interactive Power BI dashboard built to analyze PhonePe payment transactions, user behavior, transaction value, payment success rate, and demographic trends.

## 🎯 Project Objective

The objective of this project is to analyze digital payment transactions and identify key trends in transaction volume, transaction value, user behavior, payment performance, and age-group contribution.

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Modeling
- Data Visualization

## 📌 Key KPIs

- Total Transactions: 300K
- Total Transaction Value: ₹3.47B
- Unique Users: 108K
- Successful Transaction Rate: 96%

## 📈 Dashboard Features

- Transaction trends over time
- Payment status analysis
- Age segment contribution
- Service-wise transaction value
- Top users by transaction value
- Weekday vs Weekend usage
- Interactive Month and Payment Status filters

## 💡 Key Insights

- 96% of transactions were successful.
- Loans generated the highest transaction value.
- Gen X and Millennials contributed the highest transaction value.
- Weekday usage was higher than weekend usage.
- July recorded the highest transaction activity.
